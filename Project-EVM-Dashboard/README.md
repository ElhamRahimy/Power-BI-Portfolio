# Enterprise Project Portfolio & Earned Value Management (EVM) Dashboard

**Power BI | SQL Server | Microsoft Project Server | Enterprise BI | Project Controls**

## Project Overview

Designed and developed an enterprise-level Business Intelligence solution for the **central PMO of a large corporate holding group comprising hundreds of subsidiary companies**.

The solution consolidated project management data from the parent holding and **four sub-holdings**, providing centralized portfolio monitoring and standardized reporting for their respective PMO offices.

Developed using real enterprise data, the dashboards enable management to monitor project progress, financial performance, schedule deviations, Earned Value Management (EVM) indicators, and project risks at both portfolio and individual project levels.

## Data Sources & Technical Implementation

The solution was independently developed end-to-end, from database analysis and SQL query development to data integration, modeling, and Power BI dashboard design.

Project data originated from **Microsoft Project Server environments backed by Microsoft SQL Server databases** across five holding-level organizational environments.

### Key Technical Responsibilities

- **SQL Development:** Independently developed SQL queries to extract and analyze project management data from complex Microsoft Project Server databases.
- **Database Analysis:** Investigated relational database structures and identified relationships between projects, tasks, resources, schedules, costs, and progress information.
- **Data Integration:** Consolidated reporting data from the parent holding and four sub-holdings into a unified Business Intelligence solution.
- **Data Modeling:** Structured and modeled project data to support portfolio-level and individual project-level reporting.
- **EVM Analytics:** Implemented Earned Value Management indicators to evaluate project cost efficiency, schedule performance, and completion forecasts.
- **Dashboard Development:** Designed interactive Power BI reports for executive management and PMO teams.

### Technical Complexity

Microsoft Project Server databases contain sophisticated, interconnected project management data structures that require specialized knowledge of both SQL Server and enterprise project management concepts.

The main technical challenge involved independently understanding these relationships, extracting relevant information across multiple organizational environments, and transforming complex project data into consistent, meaningful management reports.

## Dashboard Features

### 1. Enterprise Project Portfolio Overview

- Consolidated project performance monitoring across the parent holding and four sub-holdings.
- Planned versus actual project progress analysis.
- Approved budget, actual expenditure, and committed cost reporting.
- Financial performance trends and multi-currency reporting.
- Project distribution by completion percentage.
- Identification of schedule deviations and underperforming projects.
- Interactive filtering and project-level performance comparison.

### 2. Earned Value Management (EVM)

Implemented key project performance indicators:

| Indicator | Description |
|---|---|
| BAC | Budget at Completion |
| PV | Planned Value |
| EV | Earned Value |
| AC | Actual Cost |
| CV | Cost Variance |
| SV | Schedule Variance |
| CPI | Cost Performance Index |
| SPI | Schedule Performance Index |
| EAC | Estimate at Completion |
| ETC | Estimate to Complete |

These indicators support the evaluation of project performance, cost efficiency, schedule health, and forecasted completion costs.

### 3. Project Schedule & Progress Analysis

- Planned versus actual progress S-Curves.
- Project milestone tracking.
- Phase-level progress monitoring.
- Schedule deviation analysis.
- Planned and actual start and finish date comparisons.

### 4. Financial Performance & Risk Monitoring

- Approved budgets and actual expenditure analysis.
- Committed cost monitoring.
- Cumulative financial performance trends.
- Project risk reporting and assessment.
- Financial and schedule performance comparisons.

## Business Value & Organizational Impact

- Established a consolidated reporting solution supporting the **parent holding's PMO and four sub-holding PMO offices**.
- Enabled portfolio visibility across a large, multi-company organizational structure.
- Supported consistent monitoring of project budgets, expenditures, progress, and performance indicators.
- Improved transparency of project cost and schedule deviations.
- Supported early identification of potential project delays, cost overruns, and performance risks.
- Provided management with actionable insights for project governance and decision-making.
