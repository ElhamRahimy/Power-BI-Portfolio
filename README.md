Power BI dashboards and business intelligence projects

### Project & Financial Performance Dashboard | Power BI

An interactive Power BI dashboard designed to monitor project progress, financial performance, and invoice management.

## Key Features:
- Project progress tracking and performance monitoring.
- Financial analysis of contract amounts, approved invoices, and received payments.
- Invoice analysis by project, client, and time period.
- Interactive KPI cards, charts, geographic maps, and dynamic filters.
- Comparative analysis to support project management and financial decision-making.

## Tools & Technologies: Power BI, DAX, Power Query, Data Cleaning & Transformation, Data Modeling, Data Visualization.

## Data Source: Excel-based forms, cleaned and transformed using Power Query before being integrated into the Power BI data model.

Note: This dashboard uses synthetic sample data for demonstration and portfolio purposes.
