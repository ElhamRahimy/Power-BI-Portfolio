## Featured Projects

### 1. Enterprise Project Portfolio & Earned Value Management (EVM) Dashboard

**Technologies:** Power BI | SQL Server | Microsoft Project Server | Enterprise BI | EVM

An enterprise-level Business Intelligence solution developed for the central PMO of a large corporate holding group comprising hundreds of subsidiary companies.

The solution consolidated real project management data from **Microsoft Project Server SQL databases across the parent holding and four sub-holdings**, supporting portfolio monitoring and standardized reporting for five PMO offices.

I independently managed the technical implementation, including complex database analysis, SQL query development, data extraction and integration, data modeling, and Power BI dashboard development.

**Key Highlights:**
- Enterprise project portfolio monitoring across five holding-level environments.
- Analysis of complex Microsoft Project Server relational databases.
- Earned Value Management (EVM), including BAC, PV, EV, AC, CV, SV, CPI, SPI, EAC, and ETC.
- Project financial performance, schedule monitoring, S-Curves, and risk reporting.
- Consolidated reporting supporting executive management and PMO decision-making.

### 3. DCMA 14-Point Schedule Assessment Dashboard

**Technologies:** Power BI | Microsoft Project | Excel | Project Controls

A Power BI dashboard developed to evaluate project schedule quality and health using **DCMA 14-Point Assessment** metrics.

Project scheduling data was exported from Microsoft Project into Excel and analyzed in Power BI to support schedule quality assessment and project controls.

**Key Highlights:**
- Assessment of project schedule quality using DCMA metrics.
- Identification of scheduling issues and potential risks.
- Visualization of schedule health indicators.
- Interactive reporting to support project monitoring and schedule improvements.
