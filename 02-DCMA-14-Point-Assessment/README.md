### DCMA 14-Point Project Schedule Assessment | Power BI

An interactive Power BI dashboard designed to evaluate project schedule quality and health based on the **DCMA 14-Point Schedule Assessment** framework.

Project scheduling data was exported from Microsoft Project (MSP) to Excel, then processed and analyzed in Power BI.

## Key Features:
- Assessment of project schedule quality using DCMA metrics.
- Analysis of schedule relationships, missing logic, leads, lags, float, constraints, and critical path.
- Interactive KPI gauges with configurable assessment thresholds.
- Visual identification of acceptable and unacceptable schedule indicators.
- Detailed metric explanations to support project monitoring and decision-making.

## Tools & Technologies: Microsoft Project (MSP), Excel, Power BI, Power Query, DAX, Data Modeling, Data Visualization.

Note: This dashboard uses synthetic sample data for demonstration and portfolio purposes.
